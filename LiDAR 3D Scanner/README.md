# Term Project Proposal

| --- | --- |
| 과목 | 오픈소스 소프트웨어 |
| 학번 | 23101164 |
| 성명 | 김재민 |
| 프로젝트명 | 저가형 LiDAR를 활용한 실내 구조 3D 스캐닝 |
| 영문명 | Low-Cost LiDAR-Based 3D Scanning of Indoor Structures |

## 제안배경

실내 공간의 구조를 입체적으로 표현하려면 여러 방향의 거리 정보를 수집해야 한다. 본 프로젝트에서는 한 방향의 거리를 측정하는 저가형 LiDAR 센서에 좌우·상하 회전 기능을 결합하여 실내 공간을 스캔하는 장치를 제작한다. 센서가 측정한 거리와 회전 각도를 3차원 좌표로 변환하고, 이를 PC에서 시각화하여 공간의 형태를 확인하는 것을 목표로 한다.

아두이노 호환 보드와 소형 서보 모터를 사용해 하드웨어 구성을 단순하게 만들고, 오픈소스 라이브러리로 데이터 수집과 시각화 기능을 구현한다. 우선 한 위치에서 보이는 실내 일부를 복원하고, 이후 벽면 추출과 치수 계산으로 발전시킨다.

## 설명

### 하드웨어 구성

| 부품 | 용도 |
| --- | --- |
| 아두이노 호환 보드 | 서보 모터 제어와 센서 데이터 수집 및 PC 전송 |
| TF-Luna 단일 지점 LiDAR 센서 | 센서가 향한 방향의 벽이나 물체까지 거리 측정 |
| SG90 서보 모터 2개 | 센서의 좌우 방향과 상하 기울기 조절 |
| 팬틸트 브래킷과 고정 받침대 | 센서와 모터를 결합하고 측정 중 장치 고정 |
| 서보용 5V 전원과 연결 부품 | 모터 전원 공급과 배선 |
| 기존 PC 또는 노트북 | 측정 데이터 처리와 3D 시각화 |

부품은 실제 판매 가격과 배송비를 확인하여 선정한다. 서보 전원과 제어 보드는 공통 접지를 구성하고, 보드와 센서의 통신 신호 전압이 다르면 레벨 변환 모듈을 사용한다.

### 구현 방법

1. **공간 스캔**  
   장치를 고정한 뒤 서보 모터로 센서의 좌우·상하 방향을 순차적으로 바꾼다. 기구가 허용하는 각도 범위에서 스캔하며, 회전 후 잠시 정지한 상태에서 거리를 측정한다. 같은 방향의 거리값을 여러 번 읽어 중앙값을 사용하고 불안정한 측정값을 줄인다.

2. **데이터 전송과 좌표 변환**  
   아두이노에서 회전 명령 각도와 거리 데이터를 PC로 전송한다. Python에서 데이터를 받아 기준 좌표계에 맞는 XYZ 좌표로 변환한다. 센서의 장착 방향과 회전축 위치를 확인하고, 필요한 보정값을 적용한다. 서보 모터의 명령 각도와 실제 회전 각도 사이의 차이는 결과 오차에 포함하여 평가한다.

3. **3D 점군 시각화와 저장**  
   변환한 좌표를 Open3D로 표시한다. 점군은 공간상의 측정 지점을 점으로 표현한 데이터로, 벽과 물체의 대략적인 형태를 확인하는 데 사용한다. 측정 데이터와 점군을 파일로 저장하고 다시 불러오는 기능을 구현한다.

4. **스캔 간격 조절과 재측정**  
   각도 간격을 조절하여 스캔 시간과 데이터 밀도를 비교할 수 있게 한다. 반복 측정값의 편차가 큰 방향은 다시 측정한다. 추가 기능으로 주변 지점과 거리 차이가 큰 구간을 더 촘촘하게 스캔하여 모서리나 물체 경계를 보완한다.

### 구현 범위

최소 구현 목표는 한 위치에서 관측 가능한 벽과 물체의 형태를 3D 점군으로 재현하고, 측정 데이터를 저장하는 것이다. 장치를 이동하며 스캔하는 기능과 건물 전체의 자동 도면 생성은 초기 구현 범위에 포함하지 않는다.

기본 기능을 완성하면 점군에서 평평한 벽면을 추출하고 주요 치수를 표시하는 기능으로 확장한다. 이후 여러 방향이나 위치에서 얻은 데이터를 같은 좌표계로 정합하여 더 넓은 공간을 복원하는 방법을 검토한다. 정밀한 건축 도면 생성은 별도의 후속 과제로 둔다.

### 오픈소스 활용과 직접 구현할 부분

- **Arduino Servo 라이브러리:** 서보 모터 제어에 활용한다.
- **Python과 pySerial:** PC에서 측정 데이터를 수신하고 관리한다.
- **NumPy와 Open3D:** 좌표 계산, 점군 처리와 3D 시각화에 활용한다.
- **직접 구현할 기능:** 스캔 순서 제어, 데이터 전송 형식, 좌표 변환과 보정, 측정값 필터링, 재측정 판단, 저장 및 불러오기 기능을 개발한다.

사용한 라이브러리와 라이선스를 정리하고, 배선도·실행 방법·샘플 데이터를 기록하여 제작 과정과 결과를 재현할 수 있게 한다.

### 검증 방법

- 줄자나 거리측정기로 잰 기준 거리와 센서 측정값을 비교한다.
- 같은 공간을 반복 스캔하여 측정값과 점군 형태의 편차를 확인한다.
- 각도 간격에 따른 스캔 시간, 측정 지점 수와 형태 재현 정도를 비교한다.
- 벽 모서리, 비스듬한 면과 재질이 다른 표면에서 누락이나 오차가 발생하는 조건을 기록한다.

센서의 명시 거리 정확도와 모터의 각도 오차를 고려하여, 초기 목표를 실내 일부의 대략적인 형태 복원으로 설정한다. 1도 단위로 회전 명령을 내리는 것을 실제 각도 정확도 1도로 간주하지 않으며, 정확도는 실측 결과로 평가한다.

## 기대효과

거리 센서와 모터를 결합하여 3차원 공간 데이터를 직접 수집하고, 좌표 변환부터 시각화까지 이어지는 처리 과정을 구현할 수 있다. 단일 지점 거리 측정 센서가 회전 기구와 결합해 공간 스캐너로 동작하는 원리를 확인할 수 있다.

스캔 간격과 재측정 기능을 통해 측정 시간과 데이터 품질의 관계를 실험할 수 있다. 또한 센서 통신, 모터 제어, 데이터 처리와 시각화에 오픈소스를 활용하며 하드웨어와 소프트웨어를 연결하는 개발 역량을 기를 수 있다.

완성한 장치는 실내 일부의 구조와 물체 배치를 확인하는 데 활용할 수 있다. 향후 벽면 추출, 치수 계산과 여러 스캔 데이터의 결합 기능을 추가하여 실내 구조 모델링 도구로 발전시킬 수 있다.
